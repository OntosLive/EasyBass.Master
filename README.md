## Исторический редакционный канон (сохранён без переписывания)

# ONTOS.BASS

**Контрабасы · мастерская · прокат · продажа · Москва.**

ONTOS.BASS не является интернет-магазином, каталогом ради каталога или обязательством регулярно производить «контент».

> Что-то реально доступно или произошло → это стало различимым → появился выпуск.

Издание может молчать. Может выпустить несколько номеров подряд. У него нет долга перед алгоритмом или контент-планом.

## Формула

**инструмент → различение → выпуск → страница → архив**

Не каждую функцию нужно превращать в платформу.
Не каждую продажу нужно превращать в воронку.
Иногда достаточно дать существующей возможности ясный адрес.

## Кто такой ONTOS.BASS

Не площадка, а передатчик.

ONTOS.BASS сообщает:

> Это существует. Вот что с этим можно сделать. Вот адрес выпуска.

## Два режима

### Обычный выпуск
Сцена, инструмент, наблюдение, предложение, рассказ.

### Короткий выпуск
Один предмет. Одна возможность. Один ясный сигнал.

## Эстетика

Газета и текст.

Без интерфейсного цирка.
Без обязательной регистрации.
Без бесконечных карточек, панелей и виджетов.

**Минимум формы, максимум различимости.**

## Нулевой закон

> Форма должна появляться быстрее, чем обязательства успевают вокруг неё зарасти.

## Технический принцип

Сначала максимально простая статическая газета:

- HTML
- CSS
- Markdown-выпуски
- Git как история
- GitHub как архив траектории

Сервер, база данных, CMS и автоматизация появляются только тогда, когда возникает реальная функция, которой без них тесно.

## Редакционная позиция

ONTOS.BASS может продавать, сдавать в аренду, сообщать, показывать и объяснять.

Но не обязан изображать из себя «цифровую экосистему».

**Сигнал сначала. Инфраструктура потом.**


## Важная коррекция 9 октября 2026

После предметной проверки прежние 3290 N.0-адресов, полученные алгоритмом перемножения ситуаций и вопросов, больше не выпускаются. Реальные короткие объявления компилируются из явно написанных записей `content/entrances-rewrite/*.json`. Отдельные N.1-исследования и исходный исследовательский атлас сохраняются, но не производятся автоматически.

**Числа прежнего выпуска в этом README являются историческими.** Актуальное количество проверенных и опубликованных HTML определяется последним успешным запуском GitHub Actions, а не количеством гипотез в исследовательском дереве.

См. [актуальную рабочую точку](docs/CURRENT-WORK-STATE.md) и [историю исправления](docs/short-entrances-20261009.md).
