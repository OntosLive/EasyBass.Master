# EASYBASS.MASTER

Газета мастерской EasyBass.

Контрабасы, прокат, продажа, ремонт, коллекция, наблюдения и объявления.

Не магазинная витрина. Скорее частная мастерская, газетное объявление и ковбойская торговая типография в одном голосе.

## Машина публикации

**Markdown → GitHub Pages → постоянный URL → архив**

- `/` — текущий выпуск
- `/archive/` — подшивка
- `/archive/001/` и далее — постоянные адреса выпусков
- `issues/*.md` — источник истины

## Канон

> Один инструмент — один ясный сигнал.

Без интерфейсного цирка. Текст, адрес, возможность связаться.
