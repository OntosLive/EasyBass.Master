# EasyBassMaster · Полевой протокол первого контрабаса

**Дата:** 11 октября 2026 года.  
**Статус:** внутренний незаполненный бланк предметной регистрации к [Архитектуре знакомства R1](meeting-architecture-r1.md). Не содержит сведений о реальных экземплярах и сам по себе ничего не публикует.

## 1. Единица регистрации

Регистрируем **один физический контрабас**, а не торговую карточку, модель, ценовой сегмент или набор фотографий.

Принцип: **идентичность экземпляра постоянна; наблюдения, звук, состояние, доступность и отношения с человеком датируются**. Новое событие дополняет историю, не стирая прежнего свидетельства. Не присваивать вымышленные номера ради прототипа.

### Паспорт экземпляра: бланк

| Поле | Что зафиксировать | Основание |
| --- | --- | --- |
| Постоянный внутренний ID | Реальный исторический номер мастерской или новый устойчивый идентификатор после проверки на дубли | Реестр / запись мастера |
| Публичное обозначение | Нейтральное название, разрешённое к публикации | Редактор / мастер |
| Дата регистрации | Когда осмотрели и записали сведения, а не предполагаемая дата изготовления | Журнал регистрации |
| Происхождение | Известно документально / сообщено владельцем / гипотеза / неизвестно | Отдельный источник для каждого утверждения |
| Конструкция и размеры | Только фактические измерения: мензура, размеры, число струн, конструктивные особенности, единицы измерения | Замер с датой и исполнителем |
| Состояние | Что именно наблюдалось, на какую дату, кем осмотрено | Запись осмотра |
| Исполнительские наблюдения | Отклик, удобство, тембр с указанием условий и наблюдателя; отделить оценку от замера | Музыкант / фрагмент |
| Возможность знакомства | Подтверждена на дату / уточняется / недоступен / исторический экземпляр | Ответственный в мастерской |
| Условия приобретения / аренды | Известны и подтверждены / обсуждаются / не предлагается / неизвестны | Только актуальное согласование |
| Права на публикацию | Разрешённые факты, фотографии, звук и история; исключения | Правообладатель / согласие |

**Нельзя** превращать «неизвестно» в «редкий», «по запросу», «авторский», «доступен» или «готов к просмотру». Имя прошлого владельца, личные контакты, договор и внутренняя цена остаются в закрытом контуре.

## 2. Свидетельство, приложенное к каждому утверждению

Для каждой содержательной записи указываются: **когда, кто, что увидел/измерил/услышал, в каких условиях, откуда известен факт и допустимо ли это публиковать**.

Разделить четыре режима:

1. **Измерено/задокументировано:** документ, дата, единицы, измеритель или фотография конкретного объекта.
2. **Сообщено:** слова мастера, владельца или музыканта с указанным источником; не превращать в независимую атрибуцию.
3. **Наблюдение/слуховое суждение:** впечатление конкретного исполнителя в конкретных условиях, не универсальное качество предмета.
4. **Гипотеза/неизвестно:** поле для дальнейшего исследования, без публичного утверждения.

**Редакционный контроль:** каждое предложение будущей страницы должно иметь один из этих статусов. Необоснованную достоверность нельзя получить красивой фотографией.

## 3. Фото: минимальная предметная серия

Для первого экземпляра достаточно **одного подтверждённого предметного портрета**. Дальше по возможности: фронт, задняя дека, бок, гриф/накладка, подставка, колковая коробка, отдельная особенность конструкции.

У каждого файла зафиксировать:

- имя файла и связанный внутренний ID экземпляра;
- дату и условия съёмки;
- автора или допустимый источник;
- разрешение на публичный показ;
- предмет кадра и честную подпись.

Фото отдельного ремонта не использовать как доказательство выполненной мастерской работы, если этот факт не документирован.

## 4. Звук: протокол сравнения A → B → A

Звук относится **к экземпляру и событию записи одновременно**. Он меняется при смене струн, настройки, музыканта, помещения, микрофона, обработки, времени и техники.

Для каждой записи фиксируются:

| Условие | Записать |
| --- | --- |
| Экземпляр и дата | ID и дата записи |
| Исполнитель и согласие | Разрешение на запись и публикацию |
| Музыкальный материал | Точный одинаковый фрагмент, регистр, способ игры: arco / pizzicato |
| Состояние инструмента | Струны, настройка, значимые изменения со дня осмотра |
| Помещение и тракт | Комната, микрофон, расстояние и положение, устройство записи |
| Уровень и обработка | Усиление, компрессия, нормализация, монтаж; применено / не применено |
| Исходник | Место хранения исходной записи и её связь с публичным файлом |
| Несовпадения условий | Всё, что препятствует честному прямому A/B |

Тест перехода: **A → B → A** с возможностью моментально вернуться к одному и тому же фрагменту. Сначала проверяется, слышно ли вообще осмысленное различие при данных условиях; заранее назначать победителя запрещено. Записи с несопоставимыми условиями можно слушать по отдельности, не выдавая за контролируемое сравнение.

## 5. Малый эксперимент: три экземпляра

Не создавать на сайте три пустые карточки. Сначала в рабочем контуре собрать три самостоятельных паспорта с реальными ID.

| Проверка | Экземпляр A | Экземпляр B | Экземпляр C |
| --- | --- | --- | --- |
| Устойчивый ID установлен | □ | □ | □ |
| Фотография конкретного экземпляра и права | □ | □ | □ |
| Осмотр, дата и основание описания | □ | □ | □ |
| Текущий статус знакомства подтверждён | □ | □ | □ |
| Есть разрешённая аудиозапись | □ | □ | □ |
| Условия записи сопоставимы | □ | □ | □ |
| Текст отделяет факт от впечатления | □ | □ | □ |
| Контакт не обещает автоматический резерв | □ | □ | □ |

Проверяем не абсолютную «ценность» инструмента, а **способность человека различать** их при честно обозначенных условиях.

## 6. Уровни готовности, без фиктивного запуска

- **P0 · Зарегистрирован:** устойчивый ID и датированный минимальный предметный паспорт в закрытом рабочем контуре.
- **P1 · Можно показать:** проверенный текст, разрешённое фото, подтверждённый публичный статус. Никаких выдуманных звуков и атрибуций.
- **P2 · Можно сравнить:** два или три реальных экземпляра с разрешёнными записями и раскрытыми условиями. Реализуется добровольное прослушивание A/B.
- **P3 · Возможно знакомство:** прямая связь, а фактические инструмент, место и время подтверждаются людьми отдельно. Никакого скрытого бронирования.

P2 не является условием P3: человек может позвонить или договориться о встрече без проигрывания звука. P3 не является условием P1: архивный инструмент можно честно показывать без обещания просмотра.

## 7. Редакционная репетиция первой страницы

Для **одного настоящего экземпляра** создать черновик, отвечающий последовательно на четыре вопроса:

1. **Что именно передо мной?** Конкретный физический предмет, устойчивый номер и видимые особенности.
2. **Откуда это известно?** Подтверждённые сведения, дата, источник, честные неопределённости.
3. **Как он отвечает?** Только доступный подтверждённый звук и конкретные исполнительские наблюдения.
4. **Что я могу сделать дальше?** Послушать другое свидетельство, позвонить, обсудить живое знакомство либо остаться в коллекции.

Сверить черновик с [каноном Придворного](courtier-foyer-canon.md) и [R1 знакомства](meeting-architecture-r1.md). Из поискового фойе человек по-прежнему вправе сразу позвонить или войти в комнату. Новый предметный маршрут **не становится обязательным третьим экраном**.

## 8. Границы и следующий предметный ход

Материалы реальных инструментов собирать сначала вне публичного Git, с проверкой прав и отсутствия чужих персональных данных. В открытый репозиторий переносить только одобренные к публикации факты/медиа. Здесь не публикуются паспортные данные, договоры, оперативный учёт, цены сделки или информация о владельцах без основания.

**Непосредственное действие:** зарегистрировать один реальный контрабас по пустому бланку, выяснить, каких сведений не хватает для правдивой предметной страницы; только затем взять второй и третий для сравнения. До этого не делать вид, будто уже существует цифровая коллекция.

**Смысловая единица следующего этапа:** не «карточка товара», а *свидетельство об экземпляре и возможности встречи с ним*.
