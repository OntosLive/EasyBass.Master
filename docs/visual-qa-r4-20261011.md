## 3. Где остаётся дизайнерская неоднородность

По фактическому конечному HTML:
- `/` использует утверждённую фотографическую комнату;
- визуальные N.0 наследуют её `room-parent.css` и используют `courtier.css` только для сценических отличий;
- `/collection/` и `/meeting/` используют прежний редакционно-газетный стиль `styles.css + foyer.css`.

Это не техническая ошибка CI. Однако человек может перейти из единого визуального Придворного к другой типографической и композиционной системе. Нужна **художественная развилка**: оставить этот переход сознательно как редакционный регистр или отдельно сцепить институциональные страницы с главным визуальным родителем. Не менять автоматически утверждённую комнату, текстовый архив и все 795 N.0.

Дополнительное семантическое наблюдение: у `/collection/` и `/meeting/` H1 содержит название бренда, тогда как смысловой заголовок страницы расположен в H2. Проверить целесообразность отдельной H1-коррекции без изменения верстки.
