# EasyBassMaster · Вход в контекст, эволюция и точка продолжения
**Срез:** 11 октября 2026. **Статус:** внутренний редакционно-технический канон для следующего захода. Эта страница не публикуется на сайте: `docs/` исключена из Jekyll. Репозиторий публичный; никаких закрытых данных здесь нет.

> **Главная формула:** «Пространство, в котором можно найти свой.»
>
> **Событие, ради которого существует система:** встреча человека с реальным инструментом.
>
> **Форма предприятия:** мастерская + частная коллекция + клуб / музыкальный салон.

## 0. Какие проекты различать

1. `easybassmaster.com` — **существовавший ранее сайт-магазин и исторический источник**. Не переписывать и не переносить в него эксперимент. Старые цены, адреса, наличие и телефоны из архива не считать текущими.
2. `OntosLive/EasyBass.Master` — **новый самостоятельный статический сайт**, готовящийся для `easybassmaster.ru`: тексты, сцена главной, N.0, N.1, архив и проверки.
3. `OntosLive/EasyMusicRent` / ONTOS.RENT — **отдельный прокатный проект и источник испытанных редакционных/сборочных принципов**. Переносить оптимальную часть метода, не копировать чужие прокатные обещания или готовые тексты.

## 1. Как возникла нынешняя архитектура

| Слой | Найденное различение | Следствие |
| --- | --- | --- |
| Обычный магазин | Товар, цена, карточка, корзина | Исторический исходный формат, не канон новой главной |
| Частная коллекция | Каждый контрабас отдельный экземпляр, а не взаимозаменяемая модель | Номер, особенности, история, сравнение |
| Мастерская | Ремесло проверяется исполнением: конструкция, отклик, удобство, работа | Предметные статьи, конкретные работы, реальные свидетельства |
| Клуб / салон | У человека есть причина прийти и вернуться вне покупки | Длительные отношения, общая музыкальная среда |
| Режиссура встречи | Посмотреть → послушать → сравнить → познакомиться → решение | Интерфейс показывает следующий осмысленный ход; цена не обязана открывать знакомство |
| Система входов | Вопрос извне заслуживает собственного ясного ответа | N.0 (поисковый вход), N.1 (самостоятельное предметное знание), комната главной |
| Фотографическая комната | Пространство раскрывается через атмосферу, настоящую структуру страницы и художественно обработанные фотографии | Один визуальный центр, много самостоятельных поисковых дверей |

**Важное ограничение на философскую формулу:** отсрочка разговора о цене означает свободу первого знакомства, а не сокрытие условий сделки. Человек может сразу спросить о стоимости. Самый доступный инструмент — полноценный вариант, а не приманка для продажи более дорогого.

**Факт со слов владельца:** более тысячи контрабасов прошли через мастерскую; позднее дополнено: около пятнадцати лет профессионального опыта и частная коллекция более пятидесяти контрабасов. Для публичных утверждений сохранять источник и актуализировать формулировку. Подробности накапливаются в [workshop-dossier.md](workshop-dossier.md), который **не является готовым «О нас»**.

## 2. Структура публичного отношения

**Единица интерфейса:** текущее состояние человека → следующий доступный осмысленный ход → изменение состояния.

- Приходит с запросом «Купить мастеровой контрабас в Москве» → получает **конкретный ответ** в N.0, реальный контакт и возможность войти в комнату.
- Хочет понять конструкцию, историю, ремонт → получает **полноценное независимое знание** в N.1 (если для темы оно создано), сохраняя право перейти к контакту напрямую.
- Заходит в главную → видит мастерскую, коллекцию, фотогалерею, атмосферу и возможность знакомства.
- Встречает физический инструмент → играет, слушает и сравнивает; решение о покупке, аренде или работе мастерской возникает внутри реальной встречи.
- Возвращается впоследствии → сохраняется возможность долгих отношений с инструментом и мастерской.

**Точки различения:** поисковый запрос ≠ экземпляр инструмента; изображение инструмента ≠ физическая встреча; запись звука ≠ живое прослушивание; познакомиться ≠ купить; покупка ≠ конец связи с коллекцией.

## 3. Оптимальная часть механизма ONTOS.RENT, реально перенесённая

- Реестр тем, гипотез, покрытие и редакционный канон; самостоятельные поисковые N.0 и содержательные N.1.
- Python **компилирует, проверяет уникальность, URL, ссылки, sitemap, рендер**, но не сочиняет произвольные H1, lead или комбинированные тексты.
- Исключена прежняя экспериментальная масса **3290 синтетических декартовых N.0**. Она не должна самопроизвольно вернуться в публичный выпуск.
- Все индивидуальные фразы N.0 подготовлены моделью, но статус `gpt6_draft` не равен персональной приёмке каждого текста владельцем.
- Общее требование ответа: **заголовок узнаёт человеческую потребность; текст разворачивает и конкретизирует именно этот ответ**, без манипулятивного универсального абзаца.
- Самостоятельные N.0 / N.1 с различными намерениями могут иметь независимые индексируемые URL и self-canonical. N.1 существует только при наличии содержательной основы.
- Отсутствуют публичные каталоги SEO-входов, выдуманные цены и мнимое наличие. Список закрытых для навигации входов служит поисковому обнаружению через sitemap; фактическая индексация измеряется отдельно.

Исходный корпус перед фотографическим экспериментом: **795 N.0, 11 N.1, 825 HTML** по канону текущего выпуска. См. [CURRENT-WORK-STATE.md](CURRENT-WORK-STATE.md), [generation-canon.md](generation-canon.md), [gpt6-modulation-canon.md](gpt6-modulation-canon.md).

## 5. Следующий глубокий слой, пока только архитектура

Из концепции «частная коллекция» вытекает постоянный **экземпляр инструмента**, не исчезающий из системы после сделки.

Рабочая исследовательская схема:

`инструмент (постоянный идентификатор) → фотографии / звук / происхождение / состояние / работы мастерской / события знакомства / история смены статуса`.

Статусы возможны: **в коллекции → готовится → доступен для знакомства → у нового владельца → возвращён для работы / в архиве**. Утверждение «у нового владельца» требует реального события, а не автоматического движения SEO-карточки. Указанные поля и статусы **пока не реализованы как БД, CRM, действующий каталог или складской учёт**.

Три возможных пользовательских действия: **посмотреть, послушать, познакомиться**. «Список знакомств» может собирать несколько интересных экземпляров без превращения их в корзину. Сравнительные записи звука ценны при одинаковых условиях, но не заменяют личного прослушивания. ИИ может впоследствии подбирать различия по траектории интереса; никаких персональных профилей или слежения на нынешнем сайте не заявлено.

**Главное различение на будущее:** SEO-адрес принадлежит **вопросу**, постоянный идентификатор принадлежит **конкретному контрабасу**, а событие встречи связывает **человека, время и инструмент**. Не подменять одно другим.

**Ближайшее безопасное завершение:** открыть и рассмотреть `easybass-room-and-foyer-preview`, оценить главную и 3–5 различных прихожих на телефоне и десктопе; если обнаружится дефект, исправлять **только** изолированную ветку. До прямого разрешения владельца **не merge**.

**Затем:** сохранять каждое проверенное новое свидетельство в досье с датой и источником; из подготовленных подтверждённых фрагментов создавать страницу «Знакомство» и первые самостоятельные биографии реальных контрабасов. Не публиковать непроверенные сведения и не превращать эксперимент в обязательную CMS.

**Критерий успеха:** человек нашёл путь от своего вопроса к содержательному ответу и дальше, если захотел, к живому знакомству. Число HTML-страниц — характеристика корпуса, не замена этому результату.
