# EasyBassMaster · запуск easybassmaster.ru

**Техническая точка: 9 октября 2026.** Цель этого этапа: сделать **https://easybassmaster.ru/** единственным каноническим адресом 807 существующих страниц и передать их в Яндекс и Google. Не расширять корпус N.0, не переделывать историю мастерской и предметную коллекцию ради запуска.

## Кто за что отвечает

- **Active.Domains:** регистрация домена и делегирование NS.
- **Timeweb:** DNS-зона домена; hosting-публикация Timeweb не используется.
- **GitHub Pages / OntosLive/EasyBass.Master:** сборка через GitHub Actions и публичная выдача сайта.
- **Search Console / Яндекс Вебмастер:** обнаружение, индексация, диагностика страниц.

## Действия в DNS (актуальность проверять по GitHub Docs)

| A | @ | `185.199.109.153` |
| A | @ | `185.199.110.153` |
| A | @ | `185.199.111.153` |
| CNAME | www | `ontoslive.github.io` |

**На скриншотах владельца от 9 октября:** четыре A и www CNAME внесены в Timeweb, домен `easybassmaster.ru` сохранён в GitHub Pages, проверка DNS ещё не прошла. Нужно подтвердить действительное делегирование NS на Timeweb и убрать прежнюю чужую `AAAA` у корня (на снимке `2a03:6f00:1:5c35:6025`). Если IPv6 нужен, вместо прежней записи допустимы только официальные IPv6-адреса GitHub Pages (`2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`). MX/SPF/DMARC не удалять, это отдельный почтовый контур.

Изменения DNS могут распространяться до 24 часов. Не трактовать недоступность домена в первые минуты как неудачу сборки GitHub.

Проверить NS/A/AAAA/CNAME из независимого DNS-резолвера, после чего нажать **Check again** на GitHub → репозиторий → Settings → Pages. Проверить **Enforce HTTPS**, сертификат, ответ `https://easybassmaster.ru/` и `www` → основной домен. Настройка пользовательского домена уже выполнялась через GitHub Pages; при публикации из GitHub Actions отдельный `CNAME`-файл не требуется.

Официальный источник: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

## Единый URL сайта

- `_config.yml`: `url: "https://easybassmaster.ru"`, `baseurl: ""`.
- `scripts/site_core.py`: `DOMAIN = "https://easybassmaster.ru"`, `BASE = ""`; запись canonical, sitemap.xml, robots.txt.
- `scripts/validate_site.py`: проверять `easybassmaster.ru` вместо прежнего хоста.
- `content/atlas/coverage.json`: 300 записанных URL должны содержать новый публичный префикс.
- `tests/test_site_pipeline.py` и `tests/test_atlas_core.py`: регрессионные проверки домена, HTML и исследовательского реестра.

Кодогенерация страниц и формулировки 781 N.0 остаются прежними. Исторический **easybassmaster.com** не трогать.

## После объединения изменений

1. Убедиться в успешной сборке **и деплое** из `main`; считать адрес опубликованным только после HTTP-проверки, не по одному сообщению об успешном коммите.
2. Открыть `https://easybassmaster.ru/`, `https://easybassmaster.ru/collection/`, один старый N.0, один новый `/vhod/<family>/<slug>/`, одну N.1 `/details/...`.
3. Проверить `https://easybassmaster.ru/robots.txt` (разрешён обход, строка `Sitemap: https://easybassmaster.ru/sitemap.xml`), `https://easybassmaster.ru/sitemap.xml` и канонические адреса отдельных HTML-страниц.
4. Убедиться, что `www.easybassmaster.ru` использует HTTPS и перенаправляет на основной адрес. Запросы без `https` должны переходить на HTTPS.
5. Подтвердить домен в **Яндекс Вебмастере** и **Google Search Console** (предпочтительно через DNS TXT). Отправить sitemap; проверять `/index.html` либо `/` как главную, коммерческие N.0 и несколько глубоких N.1.
6. Наблюдать: сколько URL обнаружено, сколько исключено, что было просканировано и проиндексировано, какие запросы приводят посетителей. Наличие sitemap **не является гарантией индексации**.
7. Если индексация N.0 идёт плохо, анализировать короткие тексты, реальную самостоятельность запросов, тематические дубли и влияние модели закрытых входов. Не генерировать ещё тысячи страниц до появления данных.

## Граница запуска

**Активно:** домен, сборка, 807 URL, canonical, robots, sitemap, поисковая проверка.

**Отложено:** фотоистория мастерской, биографии отдельных контрабасов, звукосравнение, виртуальная коллекция, динамический товарный учёт, новые массовые волны N.0.

**Статус проверки на момент написания:** исходный код подготовлен к миграции; актуальную NS/DNS/HTTPS-конфигурацию нельзя считать доказанной только по файлам репозитория. Эту часть подтверждают внешние DNS-ответы и действительный HTTPS-доступ.
