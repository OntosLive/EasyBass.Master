# Канон EASYBASS.MASTER

## 1. Газета как операционная форма
Дата. Заголовок. Текст. Выпуск. Архив.

Газета не обязана заменять реальность интерфейсом. Она говорит: **вот сигнал; вот возможность; вот адрес.**

## 2. Передатчик
EASYBASS.MASTER — это газета мастерской EasyBass. Он регистрирует то, что реально существует в хозяйственной территории.

## 3. Выпуск вместо страницы
Новая функция не обязана начинаться с нового раздела сайта.

Если появился инструмент, услуга, сцена или предложение, первым носителем может быть выпуск.

## 4. Телеграфический принцип
Для связи достаточно ясного различимого сигнала.

> Не увеличивать количество интерфейса, если можно увеличить ясность сообщения.

## 5. Не контент-маркетинг
Нет нормы публикаций.
Нет долга перед лентой.
Нет обязанности «поддерживать активность».

**Есть реальная сцена — есть выпуск. Нет сцены — редакция молчит.**

## 6. Коммерция внутри смысла
Продажа, аренда или контакт не требуют отдельного рекламного языка.

Сделка может быть одной из траекторий текста.

## 7. Постоянный адрес
Каждый выпуск получает собственный URL.

Главная полоса меняется. Выпущенное остаётся доступным.

## 8. Технический аскетизм
Статическая страница предпочтительнее приложения.
Markdown предпочтительнее CMS.
Один файл предпочтительнее пяти сервисов.
Git предпочтительнее ручного архивирования.

## 9. Редакционный тест
1. Что реально существует или произошло?
2. Что здесь нужно различить?
3. Какой минимальной формы достаточно?
4. Как человек может выйти на контакт, если ему это нужно?

## 10. Главная формула

> **EASYBASS.MASTER — бизнес как вещание: существующая возможность получает ясный сигнал и постоянный адрес.**
