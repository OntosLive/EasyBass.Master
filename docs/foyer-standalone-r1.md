# EasyBassMaster · самостоятельная прихожая R1

**Дата:** 11 октября 2026. **Статус:** самостоятельный дизайн-макет для просмотра, не принятая замена главной страницы.

## Исправление ошибки понимания

В проекте существуют **две разные страницы**, а не одна главная страница плюс технические CSS-врезки в 824 поисковых адреса.

1. **Комната**: фотографическая, уже понравившаяся главная с коллекцией, ремеслом, клубом, галереей и сценой знакомства; исходный HTML утверждён и сохраняется. На тестовом сайте: `/preview-room/`.
2. **Прихожая**: **собственный документ с собственным адресом и собственной режиссурой**; человек находится на пороге, ещё не в комнате. Отдельный исходник: `design/foyer/index.html`; тестовый адрес: `/preview-foyer/`.

Скрипт `scripts/foyer_wrap.py` ранее добавлял только приглашение-«дверь» внутрь существующих поисковых страниц. **Он не создавал самостоятельную страницу прихожей**. Следовательно, такое оборачивание нельзя повторно выдавать за выполненный запрос на вторую страницу.

## Режиссура прихожей

Прихожая служит **коротким входным сценарием**, а не дубликатом главной, каталогом услуг или текстом о коллекции.

- Надпись на пороге: «Вы у порога мастерской контрабаса».
- Главное высказывание: «Здесь можно просто войти».
- Единственное основное действие: **«Войти в мастерскую»** ведёт в комнату.
- Самостоятельный маршрут к контакту: **«Договориться о встрече»**.
- Дополнительные необязательные маршруты: коллекция, мастерская, знакомство.
- Фотография видна **сквозь дверной портал**: пользователь видит, куда войдёт. Это визуальная подсказка о комнате, не повторение её полной панорамной композиции.
- В прихожей нет повторной истории коллекции, галереи, больших рекламных блоков или сценария покупки.

Техническая первая редакция выполняется в традиции тёплой коричнево-золотой мастерской. Это **новый макет для просмотра**, он не выдается за ранее утверждённое художественное решение.

## Разделение статусов и безопасности

- **Рабочий исходник:** `design/foyer/index.html` в ветке `codex/room-foyer-integration-20261011`. `design/` исключён из Jekyll, поэтому на основной сайт файл не попадёт.
- **Предпросмотр:** GitHub Actions читает именно этот файл через `git show`, вместе с существующей фотографией. Отдельный путь `/preview-foyer/`, `noindex,nofollow`. Кнопка ведёт в `/preview-room/`.
- **Действующая главная `/` в `main`:** не меняется. Поисковые страницы N.0/N.1 и sitemap: не меняются.
- **Проверка:** отдельно валидировать HTML, настоящий переход между документами, размеры и скролл браузера при ширине 390 / 728 / 1366 пикселей, фотографии и отсутствие превращения текста в ссылки.
- **Когда будет принята прихожая:** отдельно решать, какой публичный URL дать ей и откуда вести посетителей. Текущий прототип не навязывает N.0 → прихожая → комната всем посетителям. Прямой контакт из N.0 сохраняется.

**Критерий готовности:** пользователь открывает две **разные** ссылки и получает две **разные** страницы: короткую прихожую и уже утверждённую комнату. Они соединены работающей дверью.
