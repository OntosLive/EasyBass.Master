## Текущая главная концепция

**Каждый N.0 — уже фойе. Придворный принимает индивидуальный запрос прямо в нём. Человек может немедленно позвонить либо войти напрямую в одну общую главную комнату.**

**Две сцены:** N.0-фойе → комната `/`. Без обязательного `N.0 → /foyer/ → /`.

**Исторический визуальный механизм R3/R4 (заменяется предложением R5):** утверждённая **главная комната является родительским дизайном** всех визуальных N.0. `scripts/dual_view.py` при каждой сборке извлекает её подлинный первый CSS-блок в `assets/visual/room-parent.css`. `scripts/courtier_foyer.py` монтирует каждое N.0 с теми же компонентами `topbar`, `hero`, `btn`, `hero-stats`, `card`; `courtier.css` описывает только отличия композиции фойе. Газетный `styles.css` остаётся исключительно в `/text/`. **Не создавайте третью стилистику, не копируйте вручную палитру и не придумывайте отдельную шапку/кнопки/сетки.**

**Придворный** — архетип функции маршрутизатора, а не требование нарисовать буквально человека при двери. Должность постоянна; речь и уместный визуал определяются гостем и предметом запроса.

**Реализация R2:** `scripts/courtier_foyer.py` оформляет каждый из 795 авторских N.0 как самостоятельное фойе; `scripts/dual_view.py` собирает обе версии сайта и даёт Придворному прямую дверь в `/` вместо обязательного `/foyer/`. Целая комната `/` не переписывается. Сверяйте фактическую публикацию по текущему `main` и успешной сборке GitHub Pages. Ключевые проверки: `tests/test_courtier_foyer.py`, `scripts/courtier_smoke.py`, `scripts/visual_presentation_smoke.py`.

## Инварианты, которые нельзя потерять

- Одна мастерская: частная коллекция + ремесло + клуб. Главная `/` с утверждённой композицией «Пространство, в котором можно найти свой».
- Одни источники авторского контента. Визуальные N.0 на канонических адресах и технический текстовый дубль под `/text/` с `noindex`; никаких независимых редакционных копий.
- N.0 самостоятельно отвечает на запрос, телефон доступен сразу, есть 4 диапазона + 4 реальных сведения о мастерской, дверь предоставляет **альтернативный добровольный ход**, а не обязательную процедуру.
- N.1 — самостоятельное глубокое знание; не дополнять каждый N.0 автоматически пустой второй страницей.
- Точные URL, self-canonical, sitemap и действующие контакты сохранять; текстовые /text/ не включать в публичный sitemap.
- Не выдумывать цены, наличие, атрибуцию, срок ремонта, биографии инструментов и не возобновлять механическое перемножение 3290 поисковых гипотез.
- Визуальный ряд обязан **подтверждать смысл текста и следующий ход**. Фото коллекции само по себе не является доказательством того, что мастерская выполнила конкретный ремонт.
- Не считать логическую корректность HTML и прохождение тестов эквивалентом человеческого узнавания визуальной сцены. Проверять Desktop + Phone как живую композицию.

> Один общий мир мастерской. Много индивидуальных входов. Один свободный выбор: позвонить или войти.
